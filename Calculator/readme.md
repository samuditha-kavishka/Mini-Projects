# Calculator (JavaScript)

Simple web calculator built with HTML, CSS and JavaScript.

## Description
This is a basic calculator that supports addition, subtraction, multiplication, division and decimals.  
Designed as a small learning project.

## Files
  `index.html` — main HTML file
  `style.css` — styles
  `script.js` — calculator logic

## How to run (local)
1. Clone or download the repository.
2. Open `Calculator/index.html` in your web browser (double click or right click → Open with...)

## Usage
  Click numbers and operators, then press `=` to calculate.
  Press `C` to clear.

## Notes
  This project uses `eval()` for simplicity. Do not use `eval()` with untrusted input in production.
